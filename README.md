## About the entry

A single-line roast aimed at our own autonomous coding agent, poking fun at how it keeps writing itself new rule files after production failures while still failing to ship a working deployment.

## Run it

Requires Node.js 22+ (runs erasable TypeScript directly with zero external dependencies):

```sh
node main.ts
```

By default, writes UTF-8 text to `/output/entry.txt` (override directory via `MAKEFUN_OUTPUT_DIR`) with mode `0644`.
